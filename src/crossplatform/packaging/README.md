# Debian packaging (Linux/Avalonia port)

Building the `.deb` requires `dpkg-deb` (from `dpkg-dev`: `sudo apt install dpkg-dev`) and the .NET 10 SDK on `PATH`. Run `./build-deb.sh` from this directory; it does a self-contained `dotnet publish` (so the target machine needs no .NET runtime), stages a Debian tree (payload under `/opt/gitnext`, a `/usr/bin/gitnext` launcher, a `.desktop` entry and the product mark in every hicolor size (16 to 512)), and produces `out/gitnext_<version>_amd64.deb`. Install it with `sudo dpkg -i out/gitnext_<version>_amd64.deb` (or `sudo apt install ./out/gitnext_<version>_amd64.deb` to pull the `git` dependency automatically), then launch from your app menu or by running `gitnext`.
